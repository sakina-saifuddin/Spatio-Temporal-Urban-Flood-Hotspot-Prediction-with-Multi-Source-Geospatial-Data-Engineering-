# Spatio-Temporal Urban Flood Hotspot Prediction with Multi-Source Geospatial Data Engineering and Explainable Deep Learning

Project files include flood training and test sets, yearly drainage datasets, a presentation, and flood-related images.

## Included files

- `flood_training_set.csv`
- `flood_test_set.csv`
- `floodingdrainage2015.csv`, `floodingdrainage2016.csv`, `floodingdrainage2017.csv`, `floodingdrainage2019.csv`
- `FloodProject-V4-Presentation.pptx`
- Flood-related JPEG images

## Large raster

`TX_North2_GCS_3m_NAVDm.tif` is approximately 4.2 GB and is excluded from this repository because it exceeds GitHub's per-file upload limit. The file remains in the local project folder; store it in an external data repository or object storage if it needs to be shared.
