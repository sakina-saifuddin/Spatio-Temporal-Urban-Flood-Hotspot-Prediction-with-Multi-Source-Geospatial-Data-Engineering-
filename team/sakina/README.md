# Sakina — individual workspace

Branch: `sakina`.

Use this folder for Sakina’s project notes, experiments, and work-in-progress that is not yet part of the shared pipeline. Put reviewed/reusable code in the shared `src/`, `notebooks/`, or `app/` directories through a pull request. Update this README with the agreed task/role; no assignment is assumed yet.

Do not duplicate shared datasets here. Read the data locations and handling rules in `data/README.md`.
